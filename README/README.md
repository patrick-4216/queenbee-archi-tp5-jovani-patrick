# QueenBee: Architecture logicielle

**Master 1 INGETIS · TP5 d'architecture logicielle**

## Présentation

Ce dépôt contient notre travail d'architecture logicielle pour le projet QueenBee. Il regroupe les livrables de modélisation métier, de conception des contextes et de définition des contrats de données.

## Informations du projet

- **Projet :** QueenBee
- **Spécialité :** Data
- **Binôme :** KAMGAING DOMEGNE Patrick Jovani et Nzonkouo Guy Patrick
- **Formation :** M1 INGETIS
- **Année :** 2026

## Structure du dépôt

| Dossier / fichier | Description |

## Modélisation métier

Le travail s'appuie sur l'Event Storming afin d'identifier les événements métier, les commandes, les acteurs, les politiques et les invariants du domaine QueenBee.

## Décisions d'architecture

Les ADR documentent les choix retenus, les alternatives envisagées et les compromis associés.

## État du travail

Consulter les fichiers de documentation et les ADR pour connaître les décisions prises et les points restant à valider.
